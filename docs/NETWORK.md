# ネットワークと保存データ

ゲームの基本部分は一人用です。詳細地表は、飛行位置に対応する公開データをHTTPSで取得します。データ配信側にはIPアドレスと要求した領域が伝わります。アカウント登録やAPIキーは不要です。

取得先はESA WorldCoverとCopernicus DEMの公開データ配信です。接続できないときは、手元の全球表示を使用します。すべての地域に詳細データがあるわけではありません。

セーブ・設定・撮影画像・取得キャッシュはローカルに保存します。公開リポジトリに個人のセーブや認証情報は含めていません。バグ報告へログを添付するときは、ユーザー名やローカルのパスを確認してください。
