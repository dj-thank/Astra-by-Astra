# 地球の表示・速度と元要件の点検（2026-09-13）

今回の訂正は「地球が青いままで景色が変わらない」「速度が遅すぎる」。元の20km/sという上限は、この訂正に合わせて変更した。元の出発位置・高度450kmと一つの宇宙を保ち、新規開始の機首だけを近い広域観測地帯へ向ける。セーブからの位置・姿勢は変更しない。

実ユーザーログの出発地点は約北緯12度・西経133度の太平洋。周辺巡航20km/sには達していたが、見える景色は海で、提供されていない陸地画像への404が98件あった。全球地球が消えたログではなく、地理的な出発条件・見え方・速度・読み込み表示を合わせた問題だった。

通常操作の実行試験は約106秒・6226 assertions、回復リセット0。バックアップ先を作れない場合と、壊れた主セーブから復旧して主セーブをロックした状態で保存に失敗する場合を含む。ネイティブの共有時計・日没・座標連続性も合格。すべての場所・機器で問題がないという意味ではない。

Luna/maxで、元要件と固定コミットの照合、および修正差分のレビューを各1回実施。後者で指摘された「復旧後の保存による有効バックアップ喪失」を追加修正し、連鎖した失敗ケースを実パッケージで確認した。最終コードと実行結果の取りまとめはrootが行った。

提供範囲の出典は [ESA WorldCover DATA](https://esa-worldcover.org/en/data-access)。[公式のFlatGeobuf](https://esa-worldcover.s3.eu-central-1.amazonaws.com/esa_worldcover_grid_composites.fgb)に記載された2021 RGBNIRオブジェクト名だけを抽出した。観測年、変換方法、SHA256、CC BY 4.0の表示は `Data/earth-rgbnir-coverage.json`。再生成は `Tools/Data/build_earth_coverage.py`。これは全世界の地表画像を先にダウンロードする処理ではない。
