# 動く太陽

太陽はUnrealの既存光源・周縁減光・地平線遮蔽を保ち、接近時に観測画像と動く立体プラズマを表示します。観測目標の「太陽」、またはTabで選択し、通常のFによる航行確認とOによる自動航行を使えます。自動航行の観測位置は中心から8太陽半径です。太陽へ着陸する機能はありません。

## 観測と演出

HMI光球、AIA 304 Å、GONGに基づくPFSS曲線を利用します。画像は2026年8月15日〜9月11日の合成、磁場マップの最終寄与は2026年9月11日14:04 UTCです。選択中のゲーム日時の実際の太陽活動ではありません。

96本のPFSSアーチを立体チューブにし、320本の合成噴き上がりを追加しました。観測像の局所的な変形・粒状構造の明暗・アーチに沿った発光・高さの変化は演出です。極域で観測画像が欠ける部分は合成粒状構造を使います。磁力線を流体や炎の立体観測として扱いません。

太陽に固定した座標で動き、全画像を回転スクロールしません。共有UTCの3600秒周期と固定シードを使い、30/60/90秒周期の動きは時間ラップで連続します。ポーズとロードは既存のUTC保存に従い、新しいセーブ形式は追加していません。

見かけの直径1〜5度で表面、3〜8度でプラズマが滑らかに現れます。接近時の光球は細部を観測できるよう描画上の輝度を圧縮し暖色化します。船・惑星への照明は従来の測光値を使用し、局所的な明滅で変動しません。

## 再生成

素材と出典は `Data/SolarMotion/` に収録しています。既存のSTAR共通コンテンツを導入した独立チェックアウトで、専用のUnreal Pythonコマンドレットから `Tools/Unreal/import_solar_motion.py` を実行すると、新しいSolarMotionフォルダのみを作成・更新します。従来のM_Sunは変更しません。追加素材が欠けると従来の太陽へ戻ります。

`Tools/Unreal/Build-SolarPackage.ps1` はWin64ビルドとcook/stageを行います。必要エンジンは5.8.2で、Epic Launcherのインストール記録も探索します。PCHは保持し、次回のビルドで再利用します。

軽量版では、起動時は従来の太陽を表示し、太陽の目的地選択または見かけの直径0.8度から詳細素材を非同期に先読みします。読込完了後に観測画像と立体構造を接続します。素材が読めない場合は従来表示を継続します。4Kの太陽画像とUTCに基づく動きは維持しています。負荷と音声の変更は `PERFORMANCE.md` を参照してください。

## 検証経路

`Tools/Unreal/Launch-SolarQA.ps1` はプロセスと出力を分離した実行検証です。開始時に船の位置・速度を設定し、その後は通常の飛行積分で太陽の横を通過します。位置を毎フレーム書き換える航路ではありません。`-Legacy` は従来表示、`-Movie` は実画面の8Hzサンプル、`-Lifecycle` は停止・再開・保存・読込の検査です。30fpsへエンコードした動画と実際の描画FPSは区別します。

このブランチはローカルのWindows候補です。Webサイト更新とGitHub Release公開は行いません。
