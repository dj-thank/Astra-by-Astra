# STAR — 操縦ガイド

地球の朝の地平線から、月面への着陸、土星の環の観測へ。NASAなどの公開データを使った、一人用の宇宙探査ゲームです。

## 起動

Windows版をすべて展開し、`Play-STAR.cmd` をダブルクリックしてください。EXEだけを抜き出さず、フォルダー全体を保管してください。APIキーは不要です。詳細地表は飛行中にインターネットから取得し、未取得・欠測の範囲では全球表示を使います。

更新前にはゲーム内で保存して終了してください。公開版の起動スクリプトは、その展開フォルダー内の `UserData` を使用します。別の版へ移る場合は、終了後にこのフォルダーをコピーして引き継げます。複数の版から同じ保存先を同時に使わないでください。

「探査を始める」で地球付近から開始します。初めてT.16000Mを使用するときは入力設定が開きます。各軸を端まで動かして校正し、スティックを中央、スロットルを最低位置に戻して割り当てを確定してください。

「ゆったり宇宙ツアー」では、地球、月面着陸・観測・離陸、土星の環を自動で巡ります。ジョイスティックの校正は不要です。Escで一時停止、Mで手動操縦へ切り替え、入力を確認して再開できます。手動へ切り替えた後もツアー専用の保存枠を使い、以前の通常プレイの記録を上書きしません。

ツアー後の記録は「ツアー後の航海を読み込む」から手動飛行として再開できます。通常の保存枠は「保存した航海を読み込む」で開きます。

「操縦補助」は天体付近で姿勢を安定させる補助です。遠方の宇宙に固定の上下はありません。

## 最初の旅

地球上空・夜景・朝日・夕焼け・地球を眺めるフライトは、それぞれ新しい航海の開始位置です。開始後は同じ船を普通に操縦します。朝日や日没は、船の位置・高度と実際の太陽方向に応じて変わります。

矢印キー、POVハット、Alt＋右ドラッグで、飛行を続けながら周囲を見回せます。船外視点は全周を見回せます。写真モードを使わずに景色を楽しめます。

1. 地球の地平線を見ながら、推力と視点切替を試します。
2. 目標を月にします。地球に遮られている場合は、先に空へ機首を向けて高度を上げ、地球を回り込んでください。
3. 遠距離では巡航モードを使います。操縦は続けられ、接近時には速度上限が下がります。ブレーキで停止できます。
4. 月面をスキャンし、着陸地点へ向かいます。着陸脚を出し、着陸モードに切り替え、水平に近い姿勢でゆっくり下降します。
5. 接地後は8秒間スキャンを続けて記録します。Taurus–Littrowの目標地域は北緯20.1908°・東経30.7717°付近です。
6. 離陸・上昇操作を続けて地面から離れ、脚を格納します。月から十分に離れてから土星への巡航を始めます。

着陸モードの上下移動は毎秒2mです。速すぎる降下、脚の格納、強い傾きや急斜面での接触は安全位置への復帰になります。発見記録は保持されます。地球と土星の表面には着陸できません。

## キーボード・マウス

| 操作 | キー |
|---|---|
| 推力を上げる・下げる | W / S |
| 機首の左右 | J / L、または右マウスを押して移動 |
| 機首の上下 | I / K、または右マウスを押して移動 |
| ロール | Q / E |
| 横移動 | A / D |
| 上昇・下降 | PageUp / PageDown |
| 離陸・押し続けて上昇 | F |
| 月面に降りる・出入口で帰船 | H |
| ブレーキ | Space |
| 通常・巡航の切替 | C |
| 通常・着陸モードの切替 | Z |
| 着陸脚 | G |
| 次の目標 | Tab |
| 操縦席・追従視点 | V |
| 飛行中に見回す・視線を戻す | 矢印キー・Alt＋右ドラッグ / Home |
| スキャン | Rを押し続ける |
| 写真モード・撮影 | P / F12 |
| 保存・読み込み | F5 / F9 |

写真モードではW/A/S/D・Q/Eでカメラを移動し、右マウスまたは矢印キーで見回せます。

## 月面を歩く

月面へ安全に着陸した後、Hで船を降ります。W/A/S/Dで歩き、マウスで見回せます。画面の案内で船の出入口へ戻り、近くでHを押すと帰船できます。船外活動中はツアーも待機します。F5/F9で歩行位置を保存・読み込みできます。

船外活動はキーボード・マウス操作です。月全体へ着陸できますが、写真と詳細標高の優先地域はApollo 17のTaurus–Littrowです。遠方や写真のない面では、近くと同じ細かさにはなりません。

## T.16000Mの初期割り当て

左右でヨー、前後でピッチ、ひねりでロール、スライダーで推力、POVで視線を操作します。入力設定で軸・反転・感度・ボタンを変更できます。

| ボタン | 操作 |
|---|---|
| 1 | スキャン |
| 2 | 視点切替 |
| 3 | ブレーキ |
| 4 | 着陸脚 |
| 5 | 巡航切替 |
| 6 | 次の目標 |
| 7 | 写真モード |
| 8 | メニュー |
| 9 | 視線を戻す |
| 10 | 着陸モード |
| 11 | 離陸・押し続けて上昇 |
| 12 / 13 | 保存 / 読み込み |
| 14 | 押し続けて下降。写真モード中は撮影 |
| 15 / 16 | 地球 / 土星を目標にする |

ウィンドウからフォーカスが外れたり、入力機器が切断されたりすると一時停止します。再開前にスロットルを最低位置へ戻してください。

## 保存と写真

起動スクリプトから起動すると、飛行位置・姿勢・発見記録・表示設定を `UserData/Saved/SaveGames/star-v1.json` に保存します。直前の保存は `.bak` に残ります。飛行を始めずに終了しても既存記録は上書きしません。

新しく撮る写真は `UserData/Saved/Photos` に保存します。旧版の写真は元のフォルダーに残ります。EXEを直接起動した場合はその版のSavedフォルダーが使われることがあるため、普段は同じ起動スクリプトを使ってください。データの基準時刻が異なるセーブは、位置の取り違えを防ぐため読み込めません。

## 実データと演出

天体配置・姿勢の基準は2026年9月19日00:00 UTCです。雲は過去のMODIS合成画像で、現在の天気ではありません。月全体の標高とApollo 17周辺の詳細地形、土星の環の濃淡には公開観測データを使用しています。

探査船、高速航行、操作補助、音楽・効果音はゲーム用の創作です。公転・自転は設定した世界の日時に従います。月面の微細な質感にはApollo 11の実写を使用しており、Apollo 17地点の微細地形を測定したものではありません。土星の全球写真にも極域・環に隠れた欠測部分があり、そこは周囲の帯から補っています。強調した星空は過去の実写を使った演出です。素材の出典は同梱の `CREDITS.md` を参照してください。

## 世界の日時

Escから設定を開き、UTC日時を入力してEnterで適用します。対応期間は2026年です。UTCは日本時間の9時間前です。「現実の日時に合わせる」、1時間前／後、固定・1倍・60倍・600倍を選べます。メニュー中は時刻も停止し、保存には日時と倍率を含めます。天体の時刻倍率を変えても、操縦速度を同じ倍率にはしません。

詳細陸地はESA WorldCover 2021の観測画像、水域分類も2021年です。地形はCopernicus GLO-30 Public DSM（2021 release、2011–2015年の観測）です。年月に合わせた街並みの変化・季節・実際の天気は再現しません。インターネット切断やデータが公開されていない地域では、存在しない細部を生成せず全球表示を残します。

## Quest 2 / PC VR

1. PCのQuest Linkを開き、Quest 2をQuest LinkまたはAir Linkで接続します。
2. PC側で使用するOpenXRランタイムを有効にします。
3. 通常版のSTARを起動中なら保存して終了し、`Play-STAR-VR.cmd`を開きます。

VR内のメニューは、視線で指して右トリガーまたはEnterで決定します。右スティック上下でスクロール、Homeで視点を戻します。飛行は既存のフライトスティック・キーボード・ゲームパッドの操作です。Quest単体版はありません。VR時は通常の画面写真だけでは動作確認にならず、実機の両眼表示・追従・操作と描画速度の確認が必要です。
