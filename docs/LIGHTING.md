# 光と昼夜の扱い

地球・月・土星・太陽は同じ宇宙にあります。通常の航海の位置とUTC日時が、天体の姿勢、太陽の方向、日没、地表の明暗を決めます。景色ごとの開始モードはありません。

## 直射光と反射光

太陽の円盤と照明は同じ基準から計算します。地球や月に隠れたときは、見えている太陽の割合に応じて直射光が減ります。

船の陰になる面には、周囲の地球・空・月などから来る光も反映します。その場のHDR環境を取得し、方向のある拡散光と反射へ使います。太陽の円盤と船自身はこの取得から除き、直射光や船の表示を二重に足しません。地形・画像の読み込み、移動、天体の向きが変われば更新し、別の天体へ移ったときに以前の地球の光を持ち越さないようにしています。

環境光の有効範囲は天体を基準にした座標で管理します。地球の公転を船の高速移動と取り違えて反射光を無効にしません。詳細地表にも全球表示と同じ夜景レイヤーを引き継ぎます。

## 暗い場所がどの程度見えるか

地球照は、見えている地球のうち太陽に照らされた部分、距離、向き、地表の反射率で変わります。地球の明るい面が見える影面には光が回り込みます。一方、地球の深い影では見える昼側がなくなり、反射太陽光は弱まります。大気の薄明、月光、都市光は別の寄与です。熱赤外を可視光の明るさとして足してはいません。[NASAの地球アルベドモデル](https://ntrs.nasa.gov/api/citations/19940020024/downloads/19940020024.pdf)、[NASAの夜間光の説明](https://www.earthdata.nasa.gov/topics/human-dimensions/nighttime-lights)。

露出は光源とは別です。日光が遮られた場面では、昼向けの露出下限で固定せず、画面の実際の輝度に応じて暗部へ順応します。明るい地平線を見ている場合と、陰になった船体へ視線を向けた場合では、見え方が変わります。

参考にしたMicrosoft Flight Simulatorの資料も、直接光・間接光を含む空の遮蔽と、操縦席への光漏れを重視しています。表示用の発光も物理単位で扱われています。[Ambient Occlusion](https://docs.flightsimulator.com/html/mergedProjects/How_To_Make_An_Aircraft/Contents/Modelling/Airframe/Texturing/Ambient_Occlusion.htm)、[Exterior Lights](https://docs.flightsimulator.com/msfs2024/flighting/models-and-textures/modeling/aircraft/airframe/exterior-lights/)。

## 近似と制約

環境光は低解像度の近似です。完全な光輸送シミュレーションではなく、更新時の描画負荷もあります。地球の画像は過去の観測素材で、現在の天候や完全な照明非依存アルベドではありません。夜景は表示用の合成画像を用いており、都市光の絶対光量を校正したものではありません。第三者ゲームの地図・モデル・音源は取り込んでいません。

検証では、同じ航海のまま太陽が「地平線の上→一部が隠れる→隠れる」と変化する画像と、反射光の有無による船体の陰の変化を確認します。描画確認と、実機コントローラー・VRの確認は別です。
