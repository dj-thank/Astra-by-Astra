# 停止・読込・クラッシュの調査

通常プレイでも、端末内へ飛行ログを保存します。外部への自動送信はしません。

ゲーム内メニューの「不具合調査のログを開く」で保存先を開けます。配布ZIPの標準起動では `UserData/Saved/Diagnostics`、開発用の最新版ランチャーでは `outputs/STAR-user-data/Saved/Diagnostics` にあります。

## 記録すること

- 約0.5秒ごとの位置、速度、巡航モード、推力・旋回・ブレーキ、停止状態、地球などの天体に対する位置、描画原点とカメラの座標。
- 操作したアクション、フォーカス喪失や入力機器による一時停止、惑星間巡航の許可不足による停止。
- 地形の取得開始・完了・失敗・移動に伴う中断、HTTP応答の失敗とタイムアウト。
- 物理・描画更新へ入る直前の段階、ゲーム処理の長いフレーム、地形のGPU反映や保存・読込にかかった時間。
- セッション開始と正常終了。直前の記録を順次ファイルへ反映しますが、電源断やストレージ故障時まで保証するものではありません。

アカウント情報、認証情報、機器のシリアル番号、コマンドライン全体は飛行ログへ保存しません。位置はゲーム内の位置です。エンジン標準ログにはPC上のファイルパスなどが含まれるため、共有前に内容を確認してください。

飛行ログは1回の起動につき2ファイル、合計最大約16MBで循環します。前の起動のログやセーブは自動削除しません。

## 読み込み中の挙動

地形が未取得の間は全球地図で飛行を続けます。画面には読込中・未取得を表示します。遠くへ移動したり詳細地形の範囲外へ上昇したりした場合は、不要になった取得を中断し、戻った地点を優先します。正常なキャッシュ未取得を通信エラーとは記録しません。

## 調査用のまとめを作る（開発者向け）

`python Tools/Unreal/Collect-Diagnostics.py --user-dir <UserDataの場所>` で、最新セッションの要約とZIPを `outputs/diagnostics` に作ります。`--session` で特定の記録フォルダーを選べます。保存データは変更せず、アップロードもしません。

`NO_CLEAN_EXIT_RECORD` は正常終了の記録がないという意味です。実行中、強制終了、クラッシュを、それだけで区別・断定しないでください。最後の処理段階、停止理由、エンジン標準ログを併せて調べます。
